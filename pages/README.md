# Consciousness Research Repository - Website

This directory contains the HTML website for the Consciousness Research Repository.

## Structure

```
pages/
├── index.html              # Landing page with overview
├── README.md               # This file
├── papers/                 # Individual paper pages
│   └── [paper-slug]/      # Each paper gets its own directory
│       └── index.html     # Beautiful formatted paper page
├── documentation/          # Documentation and navigation
│   └── index.html         # Full repository documentation
└── [future sections]/
```

## Development

- All pages use the same beautiful theme with animated starry backgrounds
- MathJax integration for LaTeX equations
- Material Design 3 components
- Responsive design for all devices
- Fast loading (pure HTML/CSS/JS)

## Adding New Content

1. **Papers**: Create `papers/[slug]/index.html` with formatted content
2. **Documentation**: Update `documentation/index.html` to include new content
3. **Navigation**: Update navigation links in relevant pages

## Features

- ✨ Animated starry night background
- 🎨 Material Design 3 UI components
- 📐 LaTeX math rendering
- 📱 Fully responsive design
- 🚀 Instant loading
- 🔗 Cross-page navigation
- 📖 Direct links to source markdown files
